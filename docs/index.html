安装Install

一分钟装好。Installed in a minute.

扩展还没有上架 Chrome 应用商店，目前通过“加载已解压的扩展程序”安装。The extension is not on the Chrome Web Store yet, so install it with “Load unpacked”.

  1. 解压 luna-translate-0.1.0.zip，得到 luna-translate 文件夹。Unzip luna-translate-0.1.0.zip to get a luna-translate folder.
  2. 打开 chrome://extensions，开启右上角的开发者模式。Open chrome://extensions and turn on Developer mode at the top right.
  3. 点击加载已解压的扩展程序，选择 luna-translate 文件夹。Click Load unpacked and choose the luna-translate folder.
  4. 首次安装会打开设置页，填入 API Key 即可开始使用。The settings page opens on first install — add your API key and you're ready.
隐私Privacy

数据怎么处理What happens to your data

  • API Key 保存在本机浏览器，不同步到你的 Google 账号。Your API key is kept in this browser and never synced to your Google account.
  • 只有后台脚本读取 Key，网页拿不到它。Only the background worker reads the key — web pages can't.
  • 你翻译的文字只发给你选的服务商，不经过任何第三方。Text you translate goes only to your chosen provider, never through a third party.
  • 设置页里一键删除所有已保存的数据。Delete everything the extension stored with one click in settings.
