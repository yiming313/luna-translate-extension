Luna Translate

Privacy Policy隐私政策

Last updated: November 7, 2026最后更新：2026 年 11 月 7 日

In short: Luna Translate has no server and collects nothing. Your API key and settings stay in your browser. The text you enter is sent only to the AI provider you chose, using your own API key. 简而言之：Luna Translate 没有服务器，不收集任何数据。你的 API Key 和设置只保存在你的浏览器里。你输入的文字只会通过你自己的 API Key 发送给你选择的 AI 服务商。

What the extension is这个扩展是什么

Luna Translate is a Chrome extension that translates and polishes text you type or paste into its toolbar popup, using an AI service you configure yourself (OpenRouter, OpenAI, Anthropic or Google Gemini). The developer does not operate any server, account system or analytics for it.Luna Translate 是一个 Chrome 扩展，用你自己配置的 AI 服务（OpenRouter、OpenAI、Anthropic 或 Google Gemini），翻译和润色你在工具栏弹窗里输入或粘贴的文字。开发者不运营任何服务器、账号系统或统计服务。

Data stored on your device保存在你设备上的数据

The extension stores the following in chrome.storage.local, inside your own browser profile:扩展把下列内容保存在你自己浏览器配置文件里的 chrome.storage.local 中：

  • The API key(s) you enter, the selected provider and model, any custom endpoint address, and a cached list of model names.你填写的 API Key、所选服务商和模型、自定义接口地址，以及缓存的模型名称列表。
  • Your language preferences and any custom prompts you write.你的语言偏好，以及你自己编写的提示词。

This data is not synced to your Google account, not uploaded to the developer, and not shared with anyone. It is not encrypted by the extension beyond what your browser profile provides. You can erase everything at any time with “Delete all saved data” on the settings page, or by uninstalling the extension.这些数据不会同步到你的 Google 账号，不会上传给开发者，也不会与任何人共享。除浏览器配置文件本身提供的保护外，扩展不会再对其加密。你可以随时在设置页点“删除所有已保存的数据”，或卸载扩展，清除全部内容。

Data sent to the AI provider you choose发送给你所选 AI 服务商的数据

When you press Translate or Polish, the extension sends the text you entered, together with the instruction prompt, directly from your browser to the endpoint of the provider you selected, authenticated with your own API key. When you press “Refresh list” or “Test connection”, it sends a model-list or a tiny test request to the same provider.当你点击“翻译”或“润色”时，扩展会把你输入的文字连同指令提示词，直接从你的浏览器发送到你所选服务商的接口，并使用你自己的 API Key 认证。点击“刷新列表”或“测试连接”时，会向同一服务商发送获取模型列表或一个很小的测试请求。

Once the text reaches a provider, that provider’s own terms and privacy policy apply to it. The developer cannot see or control it. If you enter a custom endpoint (for example a proxy or a local server), your text and API key are sent to that address instead, and you are responsible for trusting it. Please do not enter highly sensitive information if you are not comfortable sharing it with your chosen provider.文字到达服务商之后，适用该服务商自己的条款和隐私政策，开发者既看不到也无法控制。如果你填写了自定义接口地址（例如代理或本地服务），你的文字和 API Key 会改为发送到该地址，是否信任它由你自己决定。如果你不愿意与所选服务商共享，请不要输入高度敏感的信息。

What the extension does not do这个扩展不会做的事

  • It does not read, collect or modify the web pages you visit, and has no content scripts. It does not access your browsing history, tabs, cookies or clipboard.不读取、不收集、不修改你访问的网页，没有任何网页脚本；不访问你的浏览历史、标签页、Cookie 或剪贴板。
  • It contains no analytics, advertising, tracking or telemetry, and sets no cookies.不包含统计、广告、追踪或遥测，也不设置 Cookie。
  • It does not sell or transfer user data to third parties, does not use it for purposes unrelated to translating and polishing your text, and does not use it to determine creditworthiness or for lending.不出售或转让用户数据给第三方，不把数据用于与翻译、润色文字无关的目的，也不用于信用评估或放贷。
  • It does not download or run remote code. All code ships inside the extension package.不下载也不运行远程代码，所有代码都在扩展包内。

Permissions权限说明

  • storage — to keep your settings and API key on your device.在你的设备上保存设置和 API Key。
  • Four provider hosts四个服务商的接口 — to send your requests to the AI service you chose.把你的请求发送给你选择的 AI 服务。
  • Optional host access可选的主机访问 — never granted by default; the browser asks you only if you enter a custom endpoint, and only for that one host.默认不授予；只有当你填写自定义接口地址时，浏览器才会询问，并且只针对那一个地址。

Children儿童

The extension is a general-purpose tool and is not directed at children under 13. It collects no personal information from anyone.这个扩展是通用工具，不面向 13 岁以下儿童，也不会从任何人那里收集个人信息。

Changes to this policy政策的变更

If the extension’s data handling ever changes, this page will be updated and the date above will change before the new version is released.如果扩展处理数据的方式发生变化，会在新版本发布前更新本页面和上面的日期。
